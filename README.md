# Two Robots in an Elevator

A [make.fun](https://make.fun/c/u-motasimfuad-two-robots-in-an-elevator-8c6aeb8f) entry.

One line of awkward small talk that one robot says to another while they ride
an elevator together — machine logic showing through the politeness, a pause
neither robot wants to name, and a turn that lands on the first read.

## How it works

`main.py` is a deterministic, stdlib-only Python program. It writes a single
line (under 200 characters) to `/output/entry.txt`. No network, no randomness,
no external data.

## The line

> So... I ran 47 conversation openers through my politeness module and still
> landed on 'so'. Nice floor numbers. Very vertical.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
